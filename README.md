# ktex-texlive

TeX files for **kTeX online** (the "try it online" version of
[kTeX](https://github.com/gkerherve/KherveTeX-React)). Served by GitHub Pages
at https://gkerherve.github.io/ktex-texlive/ and read by the SwiftLaTeX
engine in the browser: one flat folder, `index.txt` lists every file.

The files come from the TeX Live packages kTeX uses (via tectonic's bundle)
plus the classes kTeX ships. Each file keeps its own licence (LPPL, GPL,
OFL and other free licences, as stated in the file or its package).
`swiftlatexxetex.fmt` is built from them by SwiftLaTeX.

Generated by `scripts/texlive_tree.mjs` in the kTeX repository; do not edit
by hand.
